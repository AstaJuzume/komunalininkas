# Darbų centras

Atnaujintas užsakymų, faktinių darbų, sutarčių ir aktų valdymo demonstracinis sprendimas.

## Įkėlimas į GitHub Pages

1. Išarchyvuokite ZIP failą.
2. Į GitHub saugyklos pagrindinį aplanką įkelkite VISUS išarchyvuotus failus: index.html, app.js, style.css, .nojekyll ir README.md. Paties ZIP nekelkite.
3. Saugyklos Settings → Pages skiltyje pasirinkite Deploy from a branch, šaką main ir aplanką / (root), tada Save.
4. Sulaukite sėkmingo publikavimo ir atidarykite Pages skiltyje pateiktą nuorodą.

Jei atnaujinate ankstesnį demo, pakeiskite index.html ir kartu įkelkite arba pakeiskite app.js bei style.css. Šioje versijoje šie trys failai veikia kartu.

## Paleidimas kompiuteryje

Atidarykite index.html naršyklėje. Visus tris programos failus laikykite tame pačiame aplanke.

## Funkcijos

- Sutarčių registras, seniūnijos ir padaliniai.
- Užsakymų sąrašas ir būsenų lenta.
- Kasdienis faktinių darbų registravimas, įskaitant darbus be išankstinio užsakymo.
- Paslaugų variantai, kiekiai, įkainiai, technika, medžiagų eilutės ir darbuotojai.
- Mėnesio suvestinės, vieno šablono aktai ir panaudotų eilučių užrakinimas.
- DVS duomenų ir perdavimo buhalterijai fakto registravimas.
- Užsakymo blanko bei akto spausdinimas ir PDF išsaugojimas per naršyklės spausdinimo langą.
- Personalo registras, darbų istorija, paieška ir CSV eksportas.
- Telefono ekranui pritaikytos formos.

## Demonstraciniai duomenys

Vardai, užsakovai, įkainiai ir dokumentai yra išgalvoti. Pakeitimai saugomi tik toje naršyklėje, kurioje dirbate. Skirtingos naršyklės ir skirtingi svetainės adresai pakeitimais nesidalija.

Vaidmenų perjungiklis imituoja peržiūras. Tikro naudotojų prisijungimo, serverio prieigos teisių ir bendros duomenų bazės nėra. DVS, buhalterija ir elektroninis pasirašymas nepajungti. Atostogų likučiai, darbo užmokestis ir tabeliai neįtraukti.

Pradinius duomenis galima atkurti per Apie demonstraciją → Atkurti demo duomenis. Prieš tai galima atsisiųsti JSON duomenų kopiją.
